# FreeCodeCamp Article Explorer

A full-stack web application for discovering and searching
freeCodeCamp News articles.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- PostgreSQL
- Drizzle ORM

## Planned Features

- Latest articles from freeCodeCamp RSS
- Keyword search
- Tag filtering
- Historical article search
- PostgreSQL full-text search
